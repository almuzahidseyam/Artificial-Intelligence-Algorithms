# Artificial Intelligence Algorithms

A collection of Artificial Intelligence algorithms and lab codes implemented in **Python** for the **Artificial Intelligence Sessional (CIT 316)** course.

## Topics Covered
- **Informed Search Algorithms**: A* Search, Greedy Best-First Search, etc.
- **Uninformed Search Algorithms**: Breadth-First Search (BFS), Depth-First Search (DFS), Uniform Cost Search.
- **Graph Coding**: Implementations of graphs and traversal algorithms used in AI.

## Technologies Used
- **Language:** Python
- **Libraries:** Standard Python libraries

## How to Run
1. Ensure Python 3.x is installed on your system.
2. Navigate to the specific lab directory (e.g., Lab-1/Informed-Search).
3. Run the python script: python script_name.py
